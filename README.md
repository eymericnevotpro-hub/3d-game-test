# 3D Game Test — Coop City

Jeu 3D coop multijoueur en première personne dans un environnement urbain. Style : cosmonautes chibi avec visière grise (placeholder pour la photo réelle du joueur).

## Stack

- Vite + TypeScript
- Three.js (rendu 3D, FPV controls)

## Lancer en local

```bash
npm install
npm run dev
```

Puis ouvre l'URL affichée (généralement `http://localhost:5173`).

## Contrôles

- `Z` `Q` `S` `D` — déplacement
- Souris — regarder
- `Échap` — libérer le curseur

## Build production

```bash
npm run build
```

Sortie dans `dist/`.
